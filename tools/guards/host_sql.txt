# THE HOST-SQL GUARD'S RULE (docs/ONE_PLATFORM_PROGRAM_2026_10_12.md D5, the dialect program's decision D5): no product
# source of the tab's apps (DataCube, engine-client, Query, Studio: HostSqlTest.java) or of Python's host
# (python/legend_lite: python/tests/test_host_sql.py) spells SQL. A host names an operation and its data; legend-lite's
# planner writes the statements, by the database's type (core's sql/dialect/HostOperations.java). Each half reads its
# language's string literals -- never comments, never Python's docstrings -- and fails on one that begins a statement:
# a keyword below, upper case, then a space; or a lower-case statement's shape. A site kept is named with its reason.

# [keywords]; [shapes], each a regular expression a literal's text may not begin with (Java's and Python's alike);
# [kept], each `file | the literal's opening text | why it is not a statement the host spells`.
